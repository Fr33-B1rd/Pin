# Win+D 三窗口回归测试

2026-11-21 在 Windows 当前会话中，使用实际打开的 ChatGPT（普通桌面绑定）、记事本（桌面挂件）和独立进程中的未绑定测试窗口。更新前后各测 10 轮，每轮按两次 Win+D。

## 复测步骤

1. 将未绑定的普通窗口放到 ChatGPT 上方，遮住它的一部分，给记事本和 ChatGPT 各留一个可点击的点。开始前用这三个点核实叠放顺序。
2. 连续按两次 Win+D，每次等待约 1.15 秒检查状态。第一次要求第三窗最小化，原来被它遮住的点命中 ChatGPT；第二次要求第三窗还原，同一点重新命中第三窗。两次都检查两扇绑定窗口的露出区域。10 轮之间不手动还原第三窗。
3. 闪动测量使用桌面复制接口以 60 fps 记录 ChatGPT 始终应当可见的一处 32×32 像素区域。以每段第 3 至 12 帧的逐像素中位数为基准，统计 RGB 平均绝对差大于 12 的帧数，折算累计画面变化时间。另用 IsIconic 轮询记录系统最小化区间；短于采样间隔的变化可能测不到。
4. 分别对三扇窗口发出系统最小化命令。确认已收起后立即执行一对 Win+D，要求两次检查均保持最小化。显式还原后再次检查。
5. 在两扇绑定窗口的标题栏分别点击，确认各自得到键盘焦点。

## 本次结果

ChatGPT 的局部画面变化中位数由 18 帧降至 12 帧（约 300 ms → 200 ms），最长由 20 帧降至 13 帧（约 333 ms → 217 ms）。普通绑定仍有可见动画。旧版第三窗在第一轮收起后一直保持最小化；新版 10 轮均按原顺序收起、还原。两扇绑定窗口的露出区域在新版 20 次检查中均命中正确窗口，记事本未被采样到最小化。手动最小化三组用例均通过，最后两扇绑定窗口均能通过实际点击获得焦点。
